# Project artwork

The active artwork is simple inline SVG in src/components/ProjectGraphic.astro. Each project has its own small line illustration, with theme-aware ink and a yellow accent. Cards and detail pages share the component. Uploaded cover images still override the graphic for future entries.

The earlier generated raster alternatives were rejected for looking too AI-generated. They are not used or shipped; local copies are retained in ignored tmp/artwork-alternates. No publication performed.
