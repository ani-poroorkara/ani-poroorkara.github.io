# Maintenance

Monthly Dependabot proposals cover npm packages and GitHub Actions, targeting `9.0v`. Minor/patch npm proposals and Action proposals are grouped. Nothing merges automatically. Dependabot configuration must exist on the repository's default branch to activate; the default branch has not been changed here.

For each proposal, review release notes and run the full verified pipeline before merging. Direct versions and the lockfile are committed. Use Node24, update `.nvmrc`/engines/workflows together for a planned runtime upgrade, and regenerate the lockfile with the supported npm version. A newer major Astro version may change Markdown/content APIs.

Check hosted editor forms after schema changes: matching enums, optional fields, upload formats/limits and filenames matter. Validate image/PDF replacement, RSS/sitemap and sharing metadata after deployment. Review public project links and résumé facts periodically.

When usage expires, resume from [progress](progress.md), the implementation plan and git status/log. The paused five-hour continuation schedule reads those checkpoints. It does not bypass account limits.
