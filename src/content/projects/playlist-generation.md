## The problem

Choosing an order for a collection of music tracks can be treated as a search problem. This project explores genetic algorithms as one way to produce a playlist.

## The approach

The program takes music files as input and searches for a playlist order. It can write the selected sequence to a text file or merge the tracks into one audio file.
